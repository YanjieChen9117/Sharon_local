# Hourly Taxi Data Documentation

## Overview

This document describes the structure and contents of the hourly aggregated taxi data file (`hourly_taxi_summary.csv`) generated by the `process_hourly_taxi_data.py` script. The dataset contains hourly summaries of NYC taxi trips with both Yellow and Green taxi data merged into single hourly records. Each row represents one hour with comprehensive features including temporal, spatial, policy, weather, and operational metrics.

## Data Source

- **Primary Data**: NYC Taxi & Limousine Commission (TLC) Trip Record Data
  - Yellow Taxi Trip Records (`yellow_tripdata_*.parquet`)
  - Green Taxi Trip Records (`green_tripdata_*.parquet`)
- **Weather Data**: Central Park Weather Records (`central_park_weather_records.csv`)
- **Holiday Data**: NYC observed holidays from `is_holiday.md`
- **CBD Zone Data**: Central Business District zone definitions from `is_cbd.md`

## Data Processing Notes

### Data Cleaning
- Trips with distance ≤ 0 or ≥ 100 miles are excluded
- Trips with fare ≤ 0 or total amount ≥ $500 are excluded
- Trips with passenger count ≤ 0 or > 6 are excluded
- Trips with duration ≤ 0 or ≥ 180 minutes are excluded
- Trips with speed ≤ 0 or ≥ 100 mph are excluded

### Feature Engineering
- **Trip Duration**: Calculated as dropoff_datetime - pickup_datetime
- **Average Speed**: Calculated as trip_distance / (trip_duration_minutes / 60)
- **Tip Rate**: Only calculated for credit card payments (payment_type = 1)
- **CBD Interactions**: Based on predefined CBD zone IDs
- **Weather Matching**: Daily weather data matched to all hours of that day

### Aggregation Method
- **Data Merging**: Yellow and Green taxi data are combined into single hourly records
- **Ratio Features**: Calculated as proportions across all trips (both Yellow and Green) within each hour
- **Average Features**: Use weighted averages based on trip counts from each taxi type
- **Total Features**: Sum across both taxi types
- **Status Features**: Use consistent values (policy, weekend, holiday, weather) for the hour
- **Taxi Type Ratios**: Represent actual proportions of Yellow vs Green trips in each hour

### Basic Analysis Examples
```python

df.groupby('day_of_week')['total_trips'].mean()

# CBD interaction patterns during rush hours

rush_hours[['cbd_inside_ratio', 'cbd_in_ratio', 'cbd_out_ratio']].mean()

# Weather impact on trip volume
df.groupby(['is_rain', 'is_snow'])['total_trips'].mean()

# Policy impact comparison
df.groupby('policy_status')['total_trips'].mean()

# Taxi type distribution analysis
print(f"Average Yellow taxi ratio: {df['yellow_ratio'].mean():.2%}")

# Hours with mixed taxi types
mixed_hours = df[(df['yellow_ratio'] > 0) & (df['green_ratio'] > 0)]

```

## File Generation

This dataset is generated by the `process_hourly_taxi_data.py` script, which:
1. Processes raw TLC parquet files (both Yellow and Green taxi data)
2. Applies data cleaning and validation
3. Integrates weather and holiday data
4. Performs feature engineering
5. Aggregates data by hour with weighted averages for combined taxi types
6. Merges Yellow and Green taxi data into single hourly records
7. Exports to CSV format

### Data Merging Process
- **Within-Hour Aggregation**: Individual trips are first aggregated by hour and taxi type
- **Cross-Type Merging**: Yellow and Green taxi hourly summaries are then combined using:
  - **Sum**: For total trips, total revenue
  - **Weighted Average**: For distance, duration, speed, fare, tip rate (weighted by trip count)
  - **Recalculated Ratios**: For CBD interactions and taxi type distributions
- **Result**: One record per hour containing merged statistics from both taxi types

For technical details on the processing pipeline, refer to the script documentation and source code.
