# 双重差分（DiD）分析报告：政策对CBD区域的影响

**分析日期：** 2025年12月8日  
**政策实施日期：** 2025年1月5日  
**数据来源：** 纽约市NTA区域小时级出租车汇总数据

---

## 执行摘要

本报告采用双重差分（Difference-in-Differences, DiD）方法，分析2025年1月5日实施的政策对纽约市CBD（中央商务区）区域出租车运营的影响。分析比较了政策前（2024年1月6日至8月31日）和政策后（2025年1月6日至8月31日）两个时期，以CBD区域作为处理组，所有其他区域作为控制组。

### 主要发现

1. **行程数量**：政策对行程数量产生了**统计上显著的负向影响**：
   - **流出行程数**：处理效应 = **-0.4089**（p = 0.0003，95%置信区间：[-0.6324, -0.1855]）***
   - **流入行程数**：处理效应 = **-1.8402**（p < 0.001，95%置信区间：[-2.0988, -1.5817]）***

2. **平均速度**：政策对平均速度产生了**统计上显著的正向影响**：
   - **流出平均速度**：处理效应 = **0.1043 mph**（p = 0.005，95%置信区间：[0.0323, 0.1764]）***
   - **流入平均速度**：处理效应 = **0.2446 mph**（p < 0.001，95%置信区间：[0.1701, 0.3192]）***

## 方法论

### DiD模型设定

双重差分模型设定如下：

**Y = β₀ + β₁×Treatment + β₂×Post + β₃×(Treatment×Post) + β₄×Controls + ε**

其中：
- **Y**：结果变量（行程数量或平均速度）
- **Treatment**：1表示CBD区域，0表示其他区域
- **Post**：1表示政策后时期（2025-01-06至2025-08-31），0表示政策前时期（2024-01-06至2024-08-31）
- **Treatment×Post**：交互项，捕捉政策效应（β₃为DiD估计值）
- **Controls**：星期几（因子变量）、小时（因子变量）、节假日、天气温度、降水量、风速、降雪量，以及财务变量：
  - 对于流出分析：outflow_total_tip, outflow_total_tolls, outflow_total_fare
  - 对于流入分析：inflow_total_tip, inflow_total_tolls, inflow_total_fare

## 详细结果

### 1. 流出行程数 (Outflow Trips) ⭐ **显著**

**处理效应（β₃）**：**-0.4089**  
**标准误**：0.1140  
**P值**：**0.0003***  
**95%置信区间**：**[-0.6324, -0.1855]**  
**显著性**：**高度显著（***）**

**解释**：政策对CBD区域相对于其他区域的流出行程数产生了**统计上显著的负向影响**。在控制了星期几、小时、节假日、天气条件和财务变量（outflow_total_tip, outflow_total_tolls, outflow_total_fare）后，政策使CBD区域的流出行程数每小时减少了约**0.41次**。

**模型统计量**：
- 调整R²：0.9877
- 残差标准误（RMSE）：17.5
- 观测数：412,812

## 讨论

### 主要发现

1. **速度改善**：政策对CBD区域的流出和流入平均速度都产生了统计上显著的正向影响。这表明政策可能改善了CBD区域的交通流，可能是由于拥堵减少或交通管理改善。流入速度的影响（0.24 mph）约为流出速度影响（0.10 mph）的2.4倍。

2. **行程数量减少**：政策对CBD区域的流出和流入行程数量都产生了统计上显著的负向影响。这表明政策可能减少了进出CBD区域的出行需求。流入行程的减少（-1.84次/小时）是流出行程减少（-0.41次/小时）的4.5倍。

3. **全面影响**：与之前仅发现流出速度显著影响的分析不同，使用扩展控制组和额外财务控制变量的更新分析显示，政策对所有四个结果变量都产生了显著影响。这表明政策对CBD交通模式的影响比最初观察到的更为广泛。

### 局限性和考虑因素

1. **平行趋势假设**：DiD方法假设在没有政策的情况下，处理组和控制组会遵循相似的趋势。这一假设应通过政策前趋势分析进行验证。

2. **控制变量**：分析控制了星期几、小时、节假日、天气条件（温度、降水量、风速、降雪量）和财务变量（总小费、总通行费、总车费）。财务变量与结果变量匹配（流出分析使用流出变量，流入分析使用流入变量）。使用fixest包对控制变量进行了共线性检查，未发现明显的共线性问题。然而，其他未观测因素（如经济条件、特殊事件）仍可能影响结果。

3. **时间周期**：分析涵盖1月6日至8月31日（政策前和政策后），确保了可比较的季节性模式。然而，长期影响可能有所不同。

4. **空间异质性**：分析将所有CBD区域进行汇总，并与所有其他区域进行比较。这些组内可能存在未在汇总分析中捕获的异质性。

5. **控制组扩展**：控制组已从CBD周边区域扩展到纽约市所有其他区域。这提供了更大、更多样化的控制组，可能提高估计的稳健性，但也引入了更大的异质性。

---

## 结论

双重差分分析显示，2025年1月5日实施的政策对CBD区域相对于其他区域的**所有四个结果变量都产生了统计上显著的影响**：

1. **速度改善**：政策提高了流出和流入平均速度：
   - 流出平均速度：**+0.10 mph**（p = 0.005）
   - 流入平均速度：**+0.24 mph**（p < 0.001）

2. **行程数量减少**：政策减少了流出和流入行程数量：
   - 流出行程：**-0.41次/小时**（p = 0.0003）
   - 流入行程：**-1.84次/小时**（p < 0.001）

这些发现表明，政策对CBD交通模式产生了**全面影响**：虽然改善了交通流（以平均速度衡量），但也减少了出行需求（以行程数量衡量）。流入行程的减少（-1.84次/小时）远大于流出行程的减少（-0.41次/小时），结合流入速度的增长（+0.24 mph）大于流出速度的增长（+0.10 mph），表明政策可能对进入CBD区域的交通产生了特别强烈的影响。

进一步的分析，包括政策前趋势验证和潜在机制检验，将加强这些结论。
