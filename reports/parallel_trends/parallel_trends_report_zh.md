## 1. 背景与目的

### 1.1 研究背景

本研究使用双重差分法(Difference-in-Differences, DiD)分析纽约市CBD拥堵收费政策对出租车行程数量和平均速度的影响。DiD分析的核心假设是**平行趋势假设(Parallel Trends Assumption)**，即在政策实施前，treatment组(CBD区域)和control组(非CBD区域)应该有相同的时间趋势。

### 1.2 检验目的

平行趋势假设的有效性直接影响DiD估计的因果推断效力。如果该假设不成立，DiD估计的政策效应可能存在偏误。本报告系统检验了以下四个结果变量的平行趋势假设：

1. **Log(流出行程数)** - 从CBD区域流出的出租车行程数(log转换)
2. **Log(流入行程数)** - 流入CBD区域的出租车行程数(log转换)
3. **Log(流出平均速度)** - 从CBD区域流出的出租车平均速度(log转换)
4. **Log(流入平均速度)** - 流入CBD区域的出租车平均速度(log转换)

### 1.3 政策时间节点

- **Pre-policy期间**: 2024年1月6日 至 2024年8月31日
- **Post-policy期间**: 2025年1月6日 至 2025年8月31日
- **Treatment组**: CBD区域的16个NTA区域
- **Control组**: 所有其他区域

## 2. 检验方法概述

本研究采用了**四种互补的方法**来检验平行趋势假设，包括informal和formal的检验方法：

### 2.1 方法1：可视化趋势检验 (Informal)

**原理**：
- 绘制treatment组和control组在整个时间段内的时间趋势图
- 按周汇总数据，观察两组在pre-policy期间的趋势是否平行

**判断标准**：
- 如果两条线在pre-policy期间（政策实施前）基本平行，支持平行趋势假设
- 如果两条线有明显的趋势差异（一条上升，一条下降，或斜率明显不同），违反平行趋势假设

### 2.2 方法2：时间趋势差异检验 (Formal)

**原理**：
只使用pre-policy数据，运行以下回归：

```
Y = β₀ + β₁*Treatment + β₂*Time + β₃*(Treatment × Time) + Controls + ε
```

其中：
- `Time`: 从第一天开始的天数（连续变量）
- `Treatment × Time`: 交互项，捕捉treatment组和control组的时间趋势差异
- `Controls`: 星期、小时、假期、天气等控制变量

**判断标准**：
- 如果 β₃ 不显著（p > 0.05），说明两组有相同的时间趋势，支持平行趋势假设
- 如果 β₃ 显著（p < 0.05），说明两组有不同的时间趋势，违反平行趋势假设

### 2.3 方法3：Event Study分析 (Formal)

**原理**：
将时间分成多个月份，为每个月创建treatment交互项：

```
Y = β₀ + β₁*Treatment + Σ βₜ*(Treatment × Monthₜ) + Controls + ε
```

其中：
- 基准月：政策实施前一个月(2024年8月)，系数设为0
- Pre-policy月份：relative month = -7 到 -1
- Post-policy月份：relative month = 1 到 12

**判断标准**：
- 如果所有pre-policy月份的系数都不显著，支持平行趋势假设
- 如果有多个pre-policy月份的系数显著，违反平行趋势假设

### 2.4 方法4：Placebo测试 (Informal)

**原理**：
在pre-policy期间选择一个虚假的政策日期(2024年5月1日)，运行DiD分析：

```
Y = β₀ + β₁*Treatment + β₂*PlaceboPost + β₃*(Treatment × PlaceboPost) + Controls + ε
```

**判断标准**：
- 如果 β₃ 不显著（p > 0.05），说明不存在虚假政策效应，支持平行趋势假设
- 如果 β₃ 显著（p < 0.05），说明存在虚假政策效应，可能违反平行趋势假设

   - 表明CBD区域的流入速度下降速度**快于**非CBD区域
   - 这是最强的违反平行趋势假设的证据

### 5.2 关键发现

#### 5.2.1 视觉检验与统计检验的对比

**重要观察**：视觉检验和formal统计检验得出了不同的结论，这反映了两种检验方法的本质差异：

1. **可视化检验（Informal）- 基本满足平行趋势**
   - 从图形上看，treatment组和control组在pre-policy期间的趋势方向大体一致
   - 两组线条相对平行，虽然存在水平差异（level difference），但趋势斜率相似
   - 周期性波动模式相似
   - 结论：从实际应用角度，**趋势差异不明显，基本可以接受平行趋势假设**

2. **Formal统计检验 - 检测到显著的趋势差异**
   - 时间趋势检验：所有变量的Treatment×Time交互项都显著（p < 0.05）
   - Event Study：大部分pre-policy月份（5-7个月）显示显著的treatment效应
   - Placebo测试：所有变量都显示显著的虚假政策效应
   - 结论：从统计角度，**检测到统计显著的趋势差异**

#### 5.2.2 如何理解这种差异？

1. **大样本效应**
   - 本研究样本量很大（206,856个pre-policy观测）
   - 在大样本下，即使**实际上很小的差异**也可能在统计上显著
   - 统计显著性 ≠ 实际显著性（practical significance）

2. **检验敏感度差异**
   - Formal统计检验对微小的线性趋势差异非常敏感
   - 即使每天的趋势差异只有0.0003（如流出行程数的Treatment×Time系数），在大样本下也会显著
   - 视觉检验更关注**肉眼可见的、实质性的趋势差异**

3. **趋势vs水平差异**
   - 两组之间主要是**水平差异**（vertical shift），而非趋势差异（slope difference）
   - 平行趋势假设关注的是趋势的平行性，不要求水平相同
   - 从图形看，两组的斜率（trend）相对接近，主要是截距（level）不同

#### 5.2.3 具体发现

1. **趋势系数的实际大小**
   - 流出行程数：Treatment×Time = 0.000273（每天差异）
   - 流入行程数：Treatment×Time = 0.000193
   - 流出速度：Treatment×Time = -0.000131
   - 流入速度：Treatment×Time = -0.000191
   - 这些系数虽然统计显著，但**实际大小很小**

2. **Event Study的模式**
   - Event Study显示pre-policy月份有显著系数，但这些系数可能反映的是：
     - 季节性差异
     - 水平差异而非趋势差异
     - 月份间的随机波动

3. **Placebo测试的解释**
   - Placebo测试发现显著效应，但效应大小相对较小（0.01-0.04）
   - 可能反映的是CBD区域和非CBD区域本身的差异，而非严重的趋势违反

## 6. 结论与建议

### 6.1 主要结论

基于四种互补的检验方法，本研究得出了**需要仔细解释的混合结论**：

#### 6.1.1 视觉检验的结论（Informal）

从可视化趋势图来看，**所有变量基本满足平行趋势假设**：

1. **趋势方向一致**：Treatment组和control组在pre-policy期间的趋势方向大体相同
2. **线条相对平行**：虽然存在水平差异，但两组的趋势线基本平行
3. **波动模式相似**：两组显示相似的周期性波动模式
4. **实际差异不大**：从实际应用角度，趋势差异不明显

#### 6.1.2 Formal统计检验的结论

从统计检验来看，**检测到统计显著的趋势差异**：

1. **时间趋势检验**：所有变量的Treatment×Time交互项都统计显著（p < 0.05）
2. **Event Study**：大部分pre-policy月份显示显著的treatment效应
3. **Placebo测试**：发现显著的虚假政策效应

#### 6.1.3 综合评估

**关键洞察**：视觉检验和统计检验的差异反映了**统计显著性与实际显著性的区别**：

1. **统计显著但效应小**：
   - 检测到的趋势差异系数很小（0.0001-0.0003每天）
   - 在大样本（20万+观测）下，微小差异也会统计显著
   - **统计显著性 ≠ 实际重要性**

2. **水平差异vs趋势差异**：
   - 两组主要是**水平差异**（不同的截距），而非趋势差异（不同的斜率）
   - 平行趋势假设关注趋势的平行性，允许水平差异存在
   - 从斜率角度看，两组相对接近

3. **实用性评估**：
   - 从**研究实践角度**，观察到的趋势差异可能**在可接受范围内**
   - DiD估计的偏误可能**不会严重到完全无效**
   - 结果仍然具有参考价值，但需要谨慎解释

### 6.2 对DiD估计的影响

考虑到上述混合结论，对DiD估计的影响评估如下：

#### 6.2.1 乐观的视角（基于视觉检验）

1. **因果推断基本有效**：
   - 视觉上趋势基本平行，DiD的基本假设大致成立
   - 估计的政策效应**可以作为有价值的参考**

2. **偏误可能较小**：
   - 检测到的趋势差异系数很小
   - 即使存在偏误，**偏误程度可能不大**

3. **结果可解释性强**：
   - 可以相对自信地将结果解释为政策效应的近似估计
   - 需要承认存在一定的不确定性

#### 6.2.2 谨慎的视角（基于Formal检验）

1. **存在统计显著的趋势差异**：
   - Formal检验显示系统性的统计显著性
   - 不能完全忽视这些统计证据

2. **可能的偏误方向**：
   - 行程数：CBD区域增长略快，DiD可能略微高估政策的负面影响或低估正面影响
   - 速度：CBD区域下降略快，DiD可能略微高估政策对速度改善的效果

3. **需要额外验证**：
   - 建议使用其他方法（趋势调整的DiD、IPW等）进行稳健性检查
   - 对比不同方法的结果，评估偏误的潜在范围

#### 6.2.3 平衡的建议

**本研究建议采取平衡的立场**：

1. **DiD结果仍然有效，但需要谨慎解释**
   - 不应完全否定DiD估计
   - 也不应将其视为完美的因果估计

2. **报告时的建议表述**：
   - ✅ "结果显示政策与...相关联"
   - ✅ "DiD估计提供了政策效应的近似评估"
   - ✅ "在承认平行趋势假设存在轻微偏离的前提下，结果表明..."
   - ❌ 避免："明确证明了因果关系"
   - ❌ 避免："完全满足DiD的所有假设"

3. **强调不确定性**：
   - 报告置信区间
   - 进行敏感性分析
   - 讨论结果的局限性

### 6.3 建议的改进方法

为了得到更可靠的因果估计，建议考虑以下方法：

#### 6.3.1 立即可行的方法

1. **趋势调整的DiD (Trend-adjusted DiD)**
   ```
   Y = β₀ + β₁*Treatment + β₂*Post + β₃*(Treatment×Post) 
       + β₄*Time + β₅*(Treatment×Time) + Controls + ε
   ```
   - 在DiD模型中加入Treatment×Time项，控制pre-policy期间的不同趋势
   - 缺点：假设线性趋势可能不够灵活

2. **基于Event Study的估计**
   - 使用Event Study框架，专注于post-policy期间的系数
   - 报告每个post-policy月份的效应，而不是单一的平均效应
   - 优点：更直观，不依赖平行趋势假设

3. **Inverse Probability Weighting (IPW)**
   - 使用倾向得分加权，使treatment组和control组在pre-policy期间更可比
   - 需要丰富的协变量来预测treatment状态

#### 6.3.2 需要额外数据的方法

1. **更精细的匹配**
   - 使用更细致的区域特征（人口密度、商业类型、历史趋势等）进行匹配
   - 构建更相似的对照组（例如，使用相邻的边缘区域作为对照）

2. **合成控制法 (Synthetic Control Method)**
   - 使用多个control区域的加权组合，构建一个"合成CBD"
   - 使得pre-policy期间的趋势完全匹配
   - 适用于treatment区域较少的情况

3. **断点回归 (Regression Discontinuity Design)**
   - 如果政策有明确的地理边界，使用边界附近的区域进行比较
   - 比较CBD边界两侧的区域，假设它们除了政策之外其他方面相似

#### 6.3.3 稳健性检查

1. **不同的对照组**
   - 尝试使用不同的对照组定义（例如，只使用曼哈顿的非CBD区域）
   - 检查结果是否对对照组选择敏感

2. **不同的时间窗口**
   - 尝试更短或更长的pre-policy/post-policy窗口
   - 检查结果是否随时间窗口变化

3. **子样本分析**
   - 按时间段（工作日vs周末、高峰vs非高峰）分别分析
   - 检查是否某些子样本更符合平行趋势假设

### 6.4 报告建议

在报告DiD分析结果时，建议：

1. **明确说明平行趋势假设的限制**
   - 透明地报告平行趋势检验结果
   - 说明估计的因果解释可能受限

2. **提供多种估计方法的结果**
   - 除了标准DiD，也报告趋势调整的DiD和Event Study结果
   - 让读者了解结果对方法选择的敏感性

3. **谨慎解释结果**
   - 避免过度强调因果效应
   - 可以将结果描述为"关联"或"相对变化"，而不是"因果效应"

4. **强调描述性发现**
   - 平行趋势的违反本身就是有价值的发现
   - 说明CBD区域和非CBD区域有不同的发展轨迹

## 7. 技术附录

### 7.1 检验统计量说明

#### 7.1.1 时间趋势检验

回归模型：
```
log(Y) = β₀ + β₁*Treatment + β₂*TimeDay + β₃*(Treatment×TimeDay) 
         + β₄*day_of_week + β₅*hour_of_day + β₆*holiday 
         + β₇*temperature + β₈*precipitation + β₉*windspeed + β₁₀*snow + ε
```

其中：
- `TimeDay`: 从2024年1月6日开始的天数（0, 1, 2, ...）
- 只使用pre-policy数据
- 使用HC3稳健标准误

原假设：H₀: β₃ = 0（两组有相同的时间趋势）

#### 7.1.2 Event Study

回归模型：
```
log(Y) = β₀ + β₁*Treatment + β₂*RelativeMonth 
         + Σₘ βₘ*(Treatment×Month_m) + Controls + ε
```

其中：
- `RelativeMonth`: 相对于基准月（2024年8月）的月份
- 基准月系数设为0
- Pre-policy月份：m = -7, -6, ..., -1
- Post-policy月份：m = 1, 2, ..., 12

原假设：H₀: βₘ = 0 for all m < 0

#### 7.1.3 Placebo测试

回归模型（只使用pre-policy数据）：
```
log(Y) = β₀ + β₁*Treatment + β₂*PlaceboPost 
         + β₃*(Treatment×PlaceboPost) + Controls + ε
```

其中：
- `PlaceboPost`: 1 if date >= 2024-05-01, 0 otherwise
- Placebo前期：2024-01-06 到 2024-04-30
- Placebo后期：2024-05-01 到 2024-08-31

原假设：H₀: β₃ = 0（不存在虚假政策效应）
